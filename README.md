# wxwork-client-web

企业微信本地客户端的 Web 工作台前端。纯静态实现：HTML + CSS + 原生 JavaScript，无框架、无构建步骤。

本仓库是从本地客户端项目中抽取出的**前端部分**，用于界面与交互层的代码评审和优化。
后端（Python HTTP 服务、SQLite 归档、企业微信适配层）**未包含**，前端所有数据均通过相对路径 `/api/*` 获取。

## 目录结构

| 文件 | 说明 |
|---|---|
| `web/index.html` | 单页骨架：顶栏、左侧导航、各功能页、登录门、弹窗 |
| `web/app.css` | 全部样式（约 1.2k 行，含主题变量与响应式规则） |
| `web/app.js` | 全部逻辑（约 2.7k 行） |
| `serve.py` | 本地静态预览服务，`/api/*` 一律返回 501 |

## 本地预览

```bash
python serve.py
```

打开 http://127.0.0.1:8787 。由于后端未包含，页面会停在登录门，仅用于查看布局、样式与组件形态。

## 页面模块

- 概览：收发量、会话数、归档规模、存储占用
- 会话/归档：会话列表、消息流、上下文查看、附件与图片
- 发送：单聊、群发、群管理（拉人/踢人/邀请/公告）
- 设置：账号口令、品牌信息、通道地址与令牌、平台绑定

## 已知可优化点

- `app.js` 单文件 2700+ 行，IIFE 内混用全局函数，缺少模块拆分
- DOM 查询未缓存，存在大量重复 `querySelector`
- 用字符串拼接 HTML，仅依赖 `esc()` 转义
- 状态集中在全局 `S` 对象，没有统一的渲染/更新层
- 无构建、无 lint、无测试

## 脱敏说明

仓库中的真实姓名、账号、会话 ID、内网地址均已替换为占位符。
